# services/hub-client —— 插件 Hub 的下行通道（本机）

设计：[13 §4 / §5.1](../../docs/design/13-plugin-hub.md)（H1）。

拉索引 · 验签 · 缓存 · 下载内容包 · 校验 sha256。**不落盘内容、不做审计、不判更新** ——
那些在 `services/catalog`（不出网）与桌面宿主 `apps/desktop/src/main/hub-host.ts`。

## 这个包的纪律

- **K6 登记：唯一为 Hub 出网的包。** 只做 GET，只带 `If-None-Match`。不带账号令牌（登录了也不带）、
  设备标识、App 版本；不回传装了什么（R12：Hub 是下行通道，不能长成数据面）。
- **什么时候能出网不归它管**：登录与否、未登录时的设置开关（HUB-Q3=B）、企业策略，都由调用方判。
  这一层不知道「用户是谁」，也就没有东西可带。
- 验签失败 / `sequence` 回退 / 不认识的 `schemaVer`：丢弃新索引、留着缓存、如实说，**不提供「仍然使用」**。
  缓存每次读都重新验签。
- 内容包用 `@evowork/hub-protocol` 的 tar 读取器解，**不调系统 `tar`**：符号链接、`..`、绝对路径整包拒绝。
- 没写许可的条目（HUB-Q5a=A）从上游固定提交取，取不到如实说要能访问哪台主机，**不退回我们的 CDN**。
