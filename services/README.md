# services —— L3 服务层

Q1=A（纯本地桌面应用）之后，这一层分成**本机常驻**与**云端**两组，边界不可混：

| 目录                                 | 位置     | 角色                                                                     | 里程碑  |
| ------------------------------------ | -------- | ------------------------------------------------------------------------ | ------- |
| [`kernel-adapter/`](kernel-adapter/) | 本机     | app-server JSON-RPC v2 适配层：收敛实验方法、展开 EvoWork 概念、降级兜底 | **M2a** |
| [`store/`](store/)                   | 本机     | 本机 sqlite（8 张表）+ 两个迁移器 + 任务状态投影                         | **M2a** |
| [`scheduler/`](scheduler/)           | 本机     | Automations 定时调度：misfire 补偿 + 设备绑定/迁移                       | M5      |
| [`ingest/`](ingest/)                 | 本机     | 文档解析管道：PDF/Office/ZIP → Markdown + 图片                           | M3      |
| [`artifacts/`](artifacts/)           | 本机     | 产物识别与索引（三信号源）+ 版本                                         | M3 / M8 |
| [`gateway/`](gateway/)               | **云端** | Responses API 网关：全量协议适配 + 三家国内模型                          | **M1**  |
| [`identity/`](identity/)             | **云端** | 账号 · 租户 · 配额 · 审计汇总 · 签名策略包下发                           | M4 / M7 |

**为什么本机的五个不拆进程、而云端的两个必须独立**：崩溃域。内核崩溃不该带走调度器，
调度器崩溃不该带走 UI（09 §1）；而云端那两个是多租户服务，与本机进程模型无关。

**云端只有四件事**（D9）：账号/租户/配额 · 企业私有源索引 · 模型网关 · 产物分享托管+审计汇总。
任何"再加一项云端职责"的设计都必须先回到 D9 重新决策 —— Q17（个人云盘）就是这样被否掉的。
