## 产物识别 100% 自建

内核有一套识别逻辑，但它**只喂 analytics、不进协议**，还硬编码 OpenAI 的 marketplace 名
（README F10），而且它的类型表里**没有 chart**（F11）。所以这条链路对我们完全无用 ——
D6 的 v0.4 修订已经把它从「复用」改成「自建」。

三个互补信号，任一命中即入索引，按绝对路径去重：

| 信号                              | 覆盖                               | 优先级 |
| --------------------------------- | ---------------------------------- | ------ |
| ① 技能显式上报（`mark_artifact`） | 官方四个技能，元数据最全           | 最高   |
| ② `FileChange` item               | agent 用 shell/python 直接写的文件 | 中     |
| ③ `post_tool_use` hook 扫描       | 绕过前两者的情况                   | 低     |

**优先级不是排序偏好，是正确性要求**：`chart` 与 `image` 都可能是 png，
区分依据是**信号源**而不是扩展名。只按时间取最后一个的话，`HOOK_SCAN` 会把
"这是图表不是插图"覆盖掉。

## 分享：本机内容离开设备的唯一常规出网路径

所以流程刻意做得重。六条硬规则里最容易在"优化体验"时被删掉的两条：

1. **不记住授权。** 做一个"以后不再询问"的勾选框，这条通道在用户第二次点分享之后
   就变成默认开启了。
2. **不做批量。** 授权接口一次只接受**一个** `artifactId` —— 这是类型上的约束，
   不是文档里的约定。

## 两种删除的语义**不同**

| 位置         | 语义           | 磁盘文件                         |
| ------------ | -------------- | -------------------------------- |
| 「我的资料」 | 真删磁盘文件   | **删掉，不进回收站**             |
| 「本地产物」 | 只移除索引条目 | **保留**（可选同时删，默认不勾） |

写反了用户会丢文件，所以它们是两个不同的函数，不是一个带布尔参数的函数。

## Visualizer 在前端

`apps/desktop/src/renderer/components/visualizer.tsx` —— 它是 **R5（XSS）的落点**，
三条不可放宽的规则在那个文件的头注释里。最关键的一条：
沙箱 iframe 给 `allow-scripts` 但**绝不给 `allow-same-origin`**，同时给等于没有沙箱。
