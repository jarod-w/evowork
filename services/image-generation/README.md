# 本机 AI 图片交付服务

设计：[15](../../docs/design/15-ai-image-generation.md)。宿主提供可信调用、用户确认与网关端口；本包不持密钥、不直接调用服务商。图片操作是权威元数据，文件是真源。付费请求不重放；提交后失联留 `outcomeUnknown`，保存/索引失败只恢复本机交付。

在设置 → 模型 → AI 图片保存 Ark 密钥并显式启用。默认 Flash，可选 Lite / Pro，型号与凭据验证只读服务商目录。生成时输入需求；编辑从 Composer 的「添加图片用于 AI 编辑」选图，或在图片卡选择「继续修改」。费用确认显示最终提示词、所选文件、模型、接口与未知金额；拒绝不会上传。

PNG / JPEG / WebP 编辑输入在原生解码前限制 10 MiB、1600 万像素，随后标准化为新 PNG 副本。输入/输出 PNG 完整结构与压缩数据校验，输出还由桌面原生解码器复核。路径限定任务真实 cwd，输出保存在 `artifacts/images/<operationId>/result.png`，原图不覆写。每个生成和编辑产物分别索引，连续编辑记录父操作。

权威表 `image_operation` 记录调用归属、模型/接口、类型、状态、哈希、额度占用与交付信息，不存原始提示词/Base64/密钥。默认任务四次付费请求、全局一个在途；结果未知也计入额度并阻止后续请求，用户明确确认可能重复收费后才允许新操作。恢复本机文件、刷新界面、内核重启不发起付费请求。删除任务取消在途及规范化副本，成功的用户文件保留；登记过的孤立临时文件在启动恢复时按 24 小时上限清理。

验证：`pnpm exec vitest run services/image-generation/test`；真内核与 Electron 集成回归：`pnpm run test:images-e2e`（本机确定性网关，不产生图片模型费用）。构建还验证图片 MCP 脱离 workspace 独立启动。真实模型样本及尚未验收的发布边界登记在设计 §15。
