# 电脑操控协议与状态机

对应 [设计 12](../../docs/design/12-computer-use.md)；当前是 CU-M1/M2 的基础模块，尚未接入原生 Helper 或桌面宿主，不代表电脑操控已经可用。

- `src/protocol.ts`：11 个固定工具的 JSON Schema、同源输入校验、错误码。未知字段、任意代码、全局快捷键均拒绝。首批粘贴仅支持纯文本。
- `src/session.ts`：每回合独立观测状态；窗口/应用/进程/缩放变化、30 秒过期、动作开始均使旧状态失效；100 次写预算、80 次提醒、重复失败/无变化停止。
- 应用准入在 `services/policy/src/computer-use.ts`，不在此复制策略。未知身份/类别拒绝；宿主必须提供可信分类，bundle id 列表不能覆盖所有终端和密码管理器。

本模块没有网络、磁盘正文存储或操作系统输入能力。工具 schema 尚未注册为 MCP，默认关闭配置尚未由宿主加载。现有 PreToolUse hook 对 cua_repl 使用临时拒绝闸门；移除此闸门前必须接通可信任务来源、应用授权、首次留存提示及真实删除路径，不能信任模型提供的来源或许可。

宿主后续必须串行执行「校验协议 → 准入/审批 → 读取或验证原生窗口 → consume → 原生动作 → complete」，并在每次原生调用前校验前台窗口、元素有效性与物理输入中断。坐标只在 Helper 确认截图与窗口一致且允许回退时使用；拖拽的双端点和距离校验、全局会话互斥、心跳、认证 socket、版本握手、持久授权存储均尚待接线。当前状态机不能替代这些原生检查。

测试由根目录 `pnpm run check` 纳入；新包不引入生产依赖。macOS TCC、签名、公证与真机测试仍待执行。
