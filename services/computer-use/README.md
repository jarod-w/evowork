# 电脑操控协议与状态机

对应 [设计 12](../../docs/design/12-computer-use.md)。固定协议已接桌面宿主与 `cua_repl` MCP；原生 Helper 已编译装配，正式发布仍为 `releaseVerified=false`，不能把假驱动的窗口测试当作原生已可用。

- `src/protocol.ts`：11 个固定工具及同源输入校验，拒绝未知字段、任意代码及全局快捷键。粘贴仅纯文本；逐字输入上限与原生一致，为 4096 UTF-16 单元。
- `src/session.ts`：窗口、应用、进程、缩放、30 秒时效及截图坐标绑定；支持审批前后不消费校验，动作开始才消费状态。拖拽两端点须在截图窗口内，距离有限。100 次写预算、80 次提醒、重复失败或无变化停止。
- `services/policy/src/computer-use.ts` 管应用准入；`computer-use-action.ts` 管动作业务风险。未识别用途默认单次确认，敏感动作确认不被完全访问代答，用户拒绝结束当前控制。

宿主执行「协议校验 → 应用准入 → 原生目标检查 → 独立业务确认 → 再验状态 → consume → 原生动作 → 重读确认」。原生 Helper 每次核验受信父进程签名、目标应用身份、前台窗口、AX 内容摘要、secure field 和中断；坐标动作还重验截图内容。认证 socket、版本握手、串行互斥与模型能力接线已存在。

根目录 `pnpm run check` 包含协议、状态机、宿主和策略测试；真实窗口假驱动用例另行运行。正式签名、公证、AX/TCC、中断延迟、剪贴板崩溃恢复及真实 MCP 历史删除仍待验收。
