# services/identity —— 账号 · 租户 · 配额 · 策略下发（**云端**）

设计：[总纲 D9](../../docs/evowork-on-codex-design.md) · [10 §8](../../docs/design/10-security-permissions-ux.md) · R11

云端四件事里的第一与第四件。数据面**只有身份与计量，无内容**（D9）。

**R11 是这个模块存在的主要理由**：Q1=A 之后企业策略无法在服务端强制拦截，只能下发到每台设备。
落法是签名策略包：

```
云端签名策略包 → 下发到每台设备 → 启动时校验签名与有效期
                                ├ 有效     → 写入 requirements.toml，锁定相关配置
                                ├ 即将过期 → 提示续期
                                └ 超期     → 自动降级为只读模式 + 明确告知原因与恢复方式
```

**降级文案必须给出恢复路径**（「请连接企业网络以更新安全策略」），否则用户只会看到产品突然不能用了 ——
这是 R11 在体验层的唯一缓解手段。
