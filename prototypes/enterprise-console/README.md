# 企业控制面原型

同一个前端里的两个入口：

- 成员网页：工作台、任务状态、我的连接、我的记忆、我的（个人信息和本人额度）
- 部门管理员仍走成员网页，多一页「部门」：本部门知识库、成员、可用 Agent
- 管理端：概览、组织、模型与成本、数据、策略、Agent、审计、运行。策略先存草稿，再由另一名管理员签发

没有后端。假数据集中在 `src/model.ts`，点击后的变化在 `src/console.tsx`。页面不要再写一份数据。

成员网页不运行 Agent。审批会记下决定，执行仍回到 EvoWork 客户端。页面顶部的身份切换只用于演示，正式产品里没有。

```sh
pnpm install
pnpm dev
```

构建后的静态文件由 `server.mjs` 提供，并把未知路径交回 `index.html`。部署脚本会装到 `119.3.221.92` 的 8888 端口。
