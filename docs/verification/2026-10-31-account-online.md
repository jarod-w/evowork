## 范围与实现

macOS arm64，真实 Electron 主进程、preload、渲染层、系统钥匙串、本机网关及 `119.3.221.92:8000` 账号服务。
密码在浏览器输入；桌面只接收授权码并通过 PKCE 换票。注册和重置邮件携带严格校验的公开授权参数，
不携带 verifier 或会话令牌。随包 `config/account.json` 提供默认地址，未登录不发账号后台请求。

已登录在 access 过期前一分钟续期，单次换票并轮转 refresh；临时网络失败保留凭据并重试，
明确吊销时清会话。退出和关闭期间的在途响应不能恢复登录。父子进程 IPC 更新网关内存令牌，不重启网关。
邮箱验证支持限频重发；密码重置吊销旧 refresh、浏览器会话和其他重置链接。

SMTP 使用 QQ 465 TLS，校验证书；587 配置要求 STARTTLS。发信接口等待服务器接受，失败返回明确的 503，
不显示已发送。授权码仅在服务器 `/etc/evowork-web.env`，权限 `600 root`。源码、测试记录和本地 `.app`
扫描 1084 个文件，实际授权码 0 命中。事务邮件 API 模式也有回归覆盖。

## 边界

当前线上地址沿用既有 8000 HTTP 测试部署；没有配置正式 HTTPS 域名。
本轮只验 macOS arm64 的账号流程，不构成其他平台、正式签名/公证或模型任务执行验收。
新注册账号仍按原设计不自动加入租户；托管模型需要管理员加入租户并配置模型。
发信投递失败会明确报错，SMTP 接受不等同于任何收件服务永远能送达；本轮 QQ 收件有独立证据。
