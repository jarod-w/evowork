## 实现

- Hub 新增 `renew-index`：只续发在线目录的序号、签发和到期时间，保留条目、包哈希、发布时间、审计及吊销列表。在线有效期仍为 7 天，剩余不超过 72 小时才续发；不续发离线目录。
- 正常 release 与续发共用发布锁和原子检查点。批准记录绑定内容/吊销/依赖文件指纹；没有记录、Git 路径不干净、内容改变、未知线上目录或回退均停止。先上传内容包与离线目录，再保存待发布在线原文；上传中断重用同一签名，确认响应丢失则回读完成记录。手动正常发布跳过已经使用的待发布序号。
- 正常发布拒绝同版本内容包被替换，保留同版本的首次发布时间，只上传当前索引引用的内容包；上传与读取有超时，私钥不进入 CI。
- 新增只读 monitor 和单文件构建，只含固定客户端公钥及协议。剩余不足 48h/24h、已经过期、网络/校验/时钟异常分别返回退出码 1/2/3/4，健康为 0。
- 客户端 IPC 增加 issuedAt/expiresAt，区分最近检查、目录签发、有效期；过期说明需要维护者更新，保留网络警告及离线包专用指引。修正目录内容列窄窗撑宽，来源信息换行、卡片网格随宽度排列。
