- 初始运行器默认 PATH 没有 Node，pnpm 回退到全局 11.25 并尝试切换/重装；未采用重装依赖的方式。后续使用缓存中项目要求的 **pnpm 10.30.3** 与已有 Node 24.22.1，不改包版本或 lockfile。
