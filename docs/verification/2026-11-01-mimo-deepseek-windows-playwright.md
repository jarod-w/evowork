## 已定位并修改

1. 原生 Windows 绝对路径与目录包含关系：产物登记、默认任务目录、附件读取、技能提炼、预览与产物识别不再依赖 `/` 前缀或单一分隔符。隐藏目录和 uploads 中间文件仍被排除。
2. Windows Python 切换：避免 `os.execve` 导致原生崩溃，保留子解释器 stdout/stderr 与退出码；办公解释器和字体候选路径使用原生路径拼接。
3. Windows 文件写入：图片原子写入使用可写文件句柄同步，不调用 Windows 不支持的目录 fsync；跨盘路径仍拒绝。数据库初始化失败时释放句柄。
4. Python 办公提取与批处理：把 Windows junction / reparse point 纳入链接拒绝；仅改变大小写的重命名确实落盘，保留不覆盖、失败回滚和越界拒绝语义。
5. CRLF：新增 LF 检出规则；模式指令升级识别对 CRLF 等价；没有重新生成或修改内核补丁。升级夹具和文本输出测试按逻辑行比较。
6. 测试可信度：身份测试要求真实完成回合与非空助手回复；验收检查器兼容 Windows 路径且不把空基线判为文件完整；审批等待针对已点击卡片，不把其他同时出现的卡片当作失败。
7. Windows 测试工具：队列、恢复与目标场景使用绑定 Python 构造原有检查点；出站观测按 PID/父 PID 归属，记录远端地址与进程类别，空观测不能作为安全通过依据。
8. 本地发布目标不再把 `C:` 误认为 SSH 主机；本地复制按包、签名、清单顺序，随机独占临时文件后原子改名。许可检查支持 Windows pnpm 启动方式。
9. 真实测试统一使用产品宿主网关与已登记模型。仅记录上游 endpoint、model、工具名称、状态码等元数据，避免将正文或凭据写入观测日志。
