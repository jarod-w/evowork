# 三步数据质量检查

## 适用场景
- 用户提供了结构化数据或表格，要求检查字段完整性、重复记录和总额一致性。
- 检查对象是可逐行核对的数据文件、表格、工作表或粘贴数据。
- 需要保留来源记录证据，便于后续回查和确认差异。

## 每次需要的信息
- **数据文件参数**：用户指定的数据文件路径；若是 Excel 或多表数据，还需指定表名和工作表名。
- **必填字段清单**：需要检查非空、非缺失的字段名称。
- **预期行数或行数口径**：固定行数、某个筛选条件后的行数，或其他可核对口径。
- **去重键**：判断同一记录的字段组合；未指定时先向用户澄清。
- **勾稽口径**：需要加总的金额或数量字段、单位、精度、币种，以及用于比对的合计或基准数来源。
- 若上述参数缺失，尤其是必填字段或去重键缺失，先向用户澄清；不要猜测或自动填补。

## 处理方法
1. **核对必填字段和行数**
   - 逐行检查所有必填字段是否存在、是否为空。
   - 统计实际行数，并与用户提供的预期行数或行数口径核对。
   - 发现缺失字段时停止继续填补，记录字段名、所在行或原始记录编号，并先向用户澄清正确口径。
2. **按明确键去重并保留原始编号**
   - 使用用户指定的去重键判断重复。
   - 每组重复只保留一条，同时完整记录被剔除记录的原始编号和所在位置。
   - 不改写原始记录编号；保留它们作为证据，确保每条结果可回查。
3. **独立勾稽总额**
   - 用独立路径重新逐项累加目标字段，并与用户提供的合计或基准数核对。
   - 金额核对前先对齐币种、单位、舍入规则和小数位。
   - 发现差异时不强行调整，列出金额明细、原始记录编号和可能原因，等用户确认后再处理。

## 交付要求
- 按检查顺序给出结论：必填字段结果、行数核对结果、去重结果和总额勾稽结果。
- 每个关键数字标明来源文件、表名或工作表，以及对应的原始记录编号。
- 缺失字段、剔除重复和勾稽差异必须逐项列出，不能只给最终数字。
- 所有结论都要基于用户指定的数据和口径；未确认的缺失或差异明确标记为待澄清。

## 复用边界
- 本技能适用于数据质量检查和核对，不负责根据检查结果自行修改、清洗或调整原始数据。
- 缺失口径、缺失字段、重复判定规则或基准总额未确认时，不要继续处理到最终结论。
- 原始记录编号是证据，不应在去重或汇总过程中丢失。
