# 06 · 资料库

> UI 基线：**截图 4**。上游：[总纲 D6 / D9 / §6.6 / §6.7](../evowork-on-codex-design.md)· K6 · Q10 · [清单 §6.2–6.3 / §12](../agent-platform-feature-list.md)
> **本模块在总纲里没有对应章节** —— 它把清单里分散的三件事（产物、记忆、分享）合成了一个一级入口。本文是它的首次成文设计，并处理它与 Q1=A / K6 的三处冲突。

## 1. 它是什么

截图 4 的资料库是一个**三栏文件浏览器**，中栏有四类节点：

```
搜索
最近                    ← 当前选中
本地产物                ← 任务生成的交付物
我的资料 ＋              ← 用户自己放的文档（截图里有一个 .md）
团队空间 ＋              ← 多人共享（截图里有「🚀资料库的100种用法」）
─────────────────
已使用 880.1 KB / 5.0 GB   升级 ›
```

主区是「最近」视图：`最近访问 / 我分享的 / 与我共享` 三个浅色 Tab + 「全部类型」筛选 + 四列表格（名称 / 所有者 / 位置 / 最近访问）+ 底部提示卡。

**它在产品里的角色**：任务是"过程"，资料库是"沉淀"。任务会被归档、会被遗忘，但产物与参考资料需要一个跨任务、按主题组织的入口。没有它，用户找上周生成的那份 PPT 只能靠翻任务列表。

## 2. 与已定决策的三处冲突（先说清楚，再谈设计）

截图 4 有四个特征强烈指向**云端个人网盘**：`所有者` 列、`与我共享` Tab、`团队空间`、`5.0 GB 配额 + 升级`。这与总纲三条硬约束直接冲突：

| 截图特征 | 冲突的决策 | 冲突点 |
|---|---|---|
| 5.0 GB 配额 + 升级 | **K6 本地优先** · **D9 云端只做四件事** | 个人云存储是第五项云端数据面职责，且"升级"意味着用户内容常态上云 |
| 团队空间（双向） | **D9** · **Q1=A** | 多人共享要求内容托管在云端，执行面在本机的前提下会分裂真源 |
| 与我共享 | **Q10 只决策了出方向** | 收件需要云端收件箱 + 通知推送，未决策 |

处理（对应 README §5 的 Q17 / Q19）：

| # | 决策项 | 本文采用的默认 | 若产品推翻默认要付什么 |
|---|---|---|---|
| **Q17** | 个人云存储 | **不做**。配额条改为本机磁盘占用（§3.5） | 需回到 D9 增列第五项云端职责 + 与 Q3 隐私口径重新对齐 + 存储成本与合规 |
| **Q19** | 团队空间 | **只读订阅**，复用 D9 已批准的"企业私有源索引"（§4） | 双向协作 = 推翻 D9，另需冲突合并、权限模型、审计 |
| — | 与我共享 | **v1 不做**，随 Q19 一并决策（§4.3） | 需云端收件箱 + 推送 |

**这不是把功能砍掉，而是把它换成不违反承诺的形态**：用户真正要的是"找到我的东西"和"看到团队给我的东西"，前者本机能做，后者用只读订阅能做。真正做不到的只有"把我的文件存到你们云上"这一件 —— 而那恰好是 Q3 承诺不做的事。

## 3. 页面设计

### 3.1 布局（截图 4 复刻）

```
┌──────────┬──────────────┬────────────────────────────────┐
│ 侧边栏    │ 中栏 272     │ 主区                            │
│ 260      │              │                                │
│ 「资料库」│ PanelHeader  │ 折叠按钮（左上）                 │
│  高亮    │  资料库  📣  │ title-2「最近」                  │
│          │              │ SegmentedControl 浅色 · 3 Tab   │
│          │ 搜索         │  ···················· 全部类型 ▾ │
│          │ 最近 ●       │ DataTable（表头 40 · 行 48）     │
│          │ 本地产物      │                                │
│          │ ─────       │ TipBanner（2 子卡 + 翻页）        │
│          │ 我的资料 ＋   │                                │
│          │  · file.md   │                                │
│          │ 团队空间 ＋   │                                │
│          │  · 🚀 …      │                                │
│          │ ─────       │                                │
│          │ QuotaFooter  │                                │
└──────────┴──────────────┴────────────────────────────────┘
```

中栏组件：`PanelHeader`（01 §5.23）· `PanelNavItem`（5.24，节奏 32）· `TreeSectionHeader`（5.25）· `TreeItem`（5.26）· `QuotaFooter`（5.27）。主区：`SegmentedControl` 浅色变体（5.10）· `DataTable`（5.28）· `TipBanner`（5.29）。**全部来自既有清单，无新组件。**

### 3.2 节点体系

| 节点 | 真源 | 可写 | 出网 |
|---|---|---|---|
| **本地产物** | 本机产物索引（08 §2）→ 指向工作空间内真实文件 | 只读（改要回任务里改） | 否 |
| **我的资料** | `~/.evowork/library/`（真实目录） | 是（拖入、新建、重命名、删除） | 否 |
| **团队空间** | 私有源下发的只读快照，缓存在 `~/.evowork/library-cache/<source>/` | 否 | **下行**（索引 + 内容拉取） |
| **最近** | 本机访问记录表（09 §4.5） | — | 否 |
| **搜索** | 本机全文索引（覆盖前三类） | — | 否 |

**「文件系统是真源」这条 D6 原则在资料库里必须坚持**：资料库不是独立存储，只是本机文件的一个视图 + 索引。因此「我的资料」里删除文件 = 真删磁盘文件（二次确认要说清），「本地产物」里删除 = 只移除索引条目并询问是否同时删文件（默认不删）。

### 3.3 「最近」视图（主区默认）

三个浅色 Tab：

| Tab | v1 | 内容 |
|---|---|---|
| 最近访问 | ✅ | 本机访问记录，含产物、我的资料、团队空间缓存。表格四列：名称 / 所有者 / 位置 / 最近访问 |
| 我分享的 | ✅ | 本机分享记录表（08 §7）：产物名 / 链接 / 有效期倒计时 / 访问次数 / 「撤销分享」 |
| 与我共享 | ❌ v1 不渲染 | 随 Q19 决策（§4.3） |

**「所有者」列在 v1 的语义**（截图里显示了 `vickymzzhou` 这类他人账号，那是云端协作产物）：
- 本地产物 / 我的资料 → 显示「我」
- 团队空间 → 显示私有源声明的发布者（组织或个人名）

若 Q17/Q19 都按默认不做，「所有者」列在个人版会几乎恒为「我」。规则：**当前视图内所有行的所有者相同时，自动隐藏该列**，把宽度让给名称 —— 避免一整列废信息。

「全部类型」筛选：文档 / 表格 / 幻灯片 / PDF / 图片 / Markdown / 数据 / 其他，来自产物索引的 `artifact_type` 与文件扩展名。

### 3.4 搜索

中栏第一项。本机全文索引，覆盖：文件名、Markdown/文本正文、产物的元数据（生成任务、生成时间、技能）。
- 索引由本机服务在文件变更时增量更新（`fs/watch` + 产物索引事件）。
- 不索引二进制内容；PDF/Office 的正文来自解析管道已产出的 Markdown（08 §3）—— **顺带解决了"上传过的文件以后能搜到"这件事**。
- 搜索结果可直接 `@` 引用进 Composer（03 §4.2 的第四类候选就是这里）。

### 3.5 配额条 → 本机占用条（Q17 默认方案）

`QuotaFooter`（01 §5.27）保留位置与视觉，语义换成本机：

```
本机占用 1.4 GB · 产物 820 MB · 解析缓存 410 MB · 索引 12 MB      清理 ›
[████████░░░░░░░░░░░░░░░░░░]
```

- 进度条基准 = 用户在设置里指定的**软上限**（默认 10 GB），超过只提醒不阻断。
- 「清理」= 可选择清理项（解析缓存、已归档任务的 rollout、失效索引），逐项显示可释放空间，**产物本体默认不在清理范围内**。
- 若 Q17 决策要做云盘，这里改为双行（本机 + 云端）即可，布局不变。

## 4. 团队空间（Q19 默认方案：只读订阅）

### 4.1 形态

复用 D9 已批准的云端职责第二项「企业私有源索引」，把它从"技能分发"扩展到"资料分发"—— **同一条通道、同一套签名校验、同一个信任模型**，不新增云端数据面职责：

```
企业私有源（云端，下行为主）
├─ 技能 / 插件包        ← 已有（05 §3.1）
└─ 资料集（新增）        ← 团队空间
     manifest: 名称 · 发布者 · 版本 · 文件清单 · 签名
     内容: Markdown / PDF / 表格 / 模板
```

### 4.2 交互

| 动作 | 行为 |
|---|---|
| 订阅 | 「团队空间 ＋」→ 输入私有源地址或从已配置源里选资料集 → 签名校验 → 落 `library-cache/` |
| 浏览 | 与「我的资料」同构的树；文件只读，可预览、可 `@` 引用、可另存到「我的资料」 |
| 更新 | 后台按 manifest 版本检查；有更新时节点旁显示 `--info` 圆点 + 「更新到 v3」 |
| 取消订阅 | 移除缓存，二次确认 |
| **写入 / 上传** | ❌ 不支持。要把本机内容给团队 → 走 Q10 的分享通道（08 §7），逐次显式授权 |

### 4.3 「与我共享」为什么 v1 不做

它需要三样 v1 没有的东西：云端收件箱（存别人分享给我的内容元数据）、跨账号推送、以及"别人的内容落到我本机"的信任与扫描策略。Q10 只决策了出方向（我把产物分享出去，默认关闭 + 有效期）。因此：

- v1：Tab 不渲染。别人分享的链接通过 IM/邮件等外部渠道送达，用户点开是**云端分享页**（浏览器），可选「保存到我的资料」（一次显式下载）。
- 这条路径不需要收件箱，也不需要推送，且用户对"内容进入本机"这一步始终有显式动作。

## 5. 与记忆系统的关系（清单 §12）

清单把记忆放在第 12 章，总纲 §6.6 定了四层实现。资料库是记忆的**可见面**——用户需要能看见并编辑 agent"记住"了什么，否则记忆是黑盒：

| 记忆层 | 总纲实现 | 在资料库里的呈现 |
|---|---|---|
| 用户级本地 | `CODEX_HOME/memories`（`memories/read` / `memories/write`） | 「我的资料」下的固定节点 **「长期记忆」**：条目列表，可查看、编辑、删除单条；`memory/reset` (exp) 对应「清空全部」 |
| 工作空间级 | `AGENTS.md` 层级 + `ext/history-notes` | 在**空间详情**页编辑（02 §4.3），不在资料库里（它属于某个空间，不属于用户） |
| 云端记忆 | `MemoryBackend` 远端实现；**Q1=A + Q3 下默认关闭** | 设置里的一个开关，默认关，开启需显式授权且**只同步结构化条目、不同步原文**（总纲 §6.6）。资料库不为它做入口 —— 默认关闭的功能不该占一级位置 |
| 会话内检索 | `thread/searchOccurrences` (exp) | 归入全局搜索（02 §7）与对话内搜索（04 §4） |

**记忆写入的可见性规则**：agent 每次写入用户级记忆，在对话流里插入一条可见的单行 item（「已记住：<摘要>」+「撤销」）。不做静默记忆 —— 这是隐私承诺的一部分，也是清单 §5.4 的自然延伸。任务级开关用 `thread/memoryMode/set` (exp)（04 §4）。

## 6. 数据模型（本机）

表结构完整定义在 09 §4，此处只列资料库用到的：

| 表 | 用途 |
|---|---|
| `artifact` | 产物索引（类型、格式、版本、所属任务、路径、分享状态）—— 08 §2 |
| `library_node` | 「我的资料」与团队空间缓存的节点树（路径、来源、只读标记、订阅源 id） |
| `library_index` | 全文索引（FTS5：路径、标题、正文、产物元数据） |
| `access_log` | 最近访问（node_id、访问时间、来源页） |
| `share` | 分享记录（产物 id、链接、有效期、访问计数、撤销状态）—— 08 §7 |
| `subscription` | 私有源订阅（源地址、资料集 id、版本、签名指纹、上次同步） |

## 7. 空态与异常

| 情况 | 表现 |
|---|---|
| 全空（新用户） | 主区空态：「资料库还是空的 / 任务生成的产物会自动出现在「本地产物」，你也可以把参考资料拖到「我的资料」」+ 「新建任务」按钮 |
| 本地产物为空但有任务 | 「这些任务还没有产生交付物」+ 解释什么算产物（08 §2.3 的类型清单） |
| 索引落后于磁盘（用户在 Finder 里改了文件） | `fs/watch` 兜底 + 手动「重新扫描」；节点旁 `--warning` 圆点表示"磁盘上已变化" |
| 文件已被外部删除 | 行保留但置灰 + 「文件已不存在」+ 「移除记录」 |
| 团队空间签名校验失败 | 拒绝加载 + `--danger` 说明 + 不提供"仍然加载" |
| 私有源不可达 | 显示缓存 + 「显示的是缓存内容（更新于 X）」 |
| 分享链接已过期 | 「我分享的」里该行置灰 + 「已过期」Badge + 「重新分享」（需再次授权，Q10） |
| 磁盘将满 | `QuotaFooter` 转 `--danger` + Toast「本机磁盘剩余不足，可能影响任务执行」+ 「清理」 |
