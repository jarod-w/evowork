# 24 · 智能体工作台

2026-11-07，按用户确认的 `evowork_agent_workspace.html` 原型接入桌面前端，并随后接通本机配置、IPC 与真实任务执行。前端评审时的历史边界保留在下文；当前行为以末节“后台接入”为准。

## 导航与页面

侧栏顺序为新建任务、自动化、插件、智能体、资料库。“插件”继续管理技能、连接器和专家；“智能体”组合角色、技能与连接器，不替换插件入口。使用现有 MainView 分发，所有子页点亮“智能体”。

工作台包含智能体列表、单个智能体创建/编辑、多智能体团队配置、流程编排与运行状态预览。列表提供全部/单体/团队筛选、搜索、编辑、删除与对话入口；单体配置包含角色说明、工作指令、技能和连接器，并显示实时预览。团队包含主控、专业成员、协作方式与节点配置。

## 前端评审时的数据与交互边界（历史）

用户明确要求先评审前端，因此这一阶段允许**明确标注**的前端示例；这不是已安装角色、已连接工具或真实任务。示例与编辑结果只存 React 状态，切换一级导航保留已保存配置，刷新页面后恢复示例。页面持续提示“前端预览”，保存反馈明确“暂存于本次会话”。不写文件、localStorage、数据库或后台配置，不调用模型、内核或新增网络接口。

对话入口只预览任务和能力配置；运行页面使用本地计时器演示当前节点、并行汇合、人工确认、停止与完成。展示为模拟日志和模拟输出，离开页面清理计时器。运行期间须先停止才能修改流程。未保存修改与正在运行的演示共用现有离开确认机制。

连接器为配置选项示意，选中不表示已连接或已授权。国内生态仍未实现。团队保存成员快照，删除单体不隐式修改已保存团队；移除负责流程节点的成员前，先调整节点执行角色。

## 组件与适配

复用 01 §5 的 PillButton、IconButton、Badge、SegmentedControl、SearchInput、EmptyState、Dialog。卡片、配置面板与流程节点是页面内的组合排版，不引入新通用控件或 UI 库。样式只使用现有 token，沿用 1100 / 760 / 480 断点；宽屏显示并列内容，窄窗单列并允许操作区换行，复用应用的侧栏折叠机制。

前端模型与示例集中在 `agent-workspace-state.ts`，页面通过 `items` / `onItemsChange` 接收配置，示例初始化在 App 层。后续接入后台时替换数据来源和保存回调；本轮不预先定义后台协议，也不复用专家的“创建”接口冒充完整智能体保存。

## 后台接入（2026-11-07）

本轮取消产品中的示例初始化与计时器模拟。配置及团队成员/节点快照进入本机 sqlite 权威表；新增迁移沿用备份、失败回滚、禁止旧版本打开新库的规则。IPC 仅暴露列表、单条保存/删除、启动、读取运行与人工决策，不接收模型密钥。未实现的国内连接器不能保存为可执行能力。运行中的团队须先停止才能删除配置，避免失去监控入口。

单体通过既有发送链创建真实任务；角色说明与工作指令作为任务级 developer instructions 快照保存，后续回合沿用快照，编辑或删除配置不改变已创建任务。能力选择是工作偏好，仍受现有技能安装、连接器信任和工具审批约束，不作为权限白名单或新授权。

团队职责、团队工作指令与用户需求共同传给各节点。团队由本机服务执行有界批次：handoff/custom 逐节点；parallel 首节点→中间并行→末节点；supervisor 前两位专业成员并行，其余按序。并发最多三节点，遵守用户调低的并发和任务预算；每节点是独立的真实任务，沿用同一工作目录，前批真实回复作为下批输入。每节点记录任务 id、真实完成/失败和输出；人工条件在真实输出后等待用户确认，review 条件要求用户复核真实输出并明确确认才放行。失败停止后续批次；停止中断已启动任务，在途创建返回后也必须中断。重启后未完成运行标为中断，不自动重投。UI 可查看真实节点任务并使用现有审批界面。

所有执行仍经 kernel-adapter 的 app-server v2 与现有 Responses 网关，不新增出网路径、不修改内核。MiMo 测试沿用已有 private 适配预设，密钥只通过测试进程环境传递。

2026-11-07 扩展测试补充：停止/失败收尾与重启恢复须在 `turn/interrupt` 后枚举并终止节点的后台终端，复查清空后才算确认停止；仅中断回合不足以保证本机命令退出。新实验接口经 kernel-adapter 收敛，缺失或失败必须明确标记停止未确认；协议依赖与降级见总纲补充及 09 §3.3。
