# 19 · 文件交付、工作区差异与磁盘撤销

2026-10-17 用户要求接续补齐文件归属与发现、明确打开事件、完整差异与磁盘撤销及 Office 预览。

- **归属与发现分开**：FileChange、带任务身份的技能上报、本机文件工具显式登记证明任务归属；扫描只发现工作区变化，显示「来源待确认」，不冒充产物。开始生成前的技能上报保留意图，文件真正落盘后再发布。
- **明确打开**：随包 `workspace_files` MCP 提供列出、登记、打开文件。宿主将原生 MCP 身份与在途调用核对，限制为任务工作区内普通文件；打开只发本机 UI 事件，不从助手措辞推断。用户点击路径及文件卡复用同一预览入口。
- **差异与撤销**：本机 artifacts 服务维护任务/回合开始快照，工具完成和回合结束核对磁盘，覆盖 shell/Python 写入、创建、修改和删除。任务范围展示从开始到当前的净差异；原生 FileChange 保留为历史与旧任务兜底。二进制显示大小及内容变化，不编造文本 diff。
- **D6 的限定例外**：用户本次要求磁盘撤销，因此允许在应用私有目录保存有容量上限的内容寻址撤销副本及清单。产物索引仍不存内容，不增加云端存储。超限、软链、读取失败必须显示，不承诺可撤销。撤销需界面确认，运行中拒绝；按记录的后态哈希核对，外部改动则拒绝，避免覆盖用户的新工作。每个文件原子替换，创建撤销为删除，删除撤销为恢复；恢复后刷新列表、预览与差异。
- **Office**：优先使用本机 LibreOffice 离线转换 PDF，再由已安装办公扩展的 PDFium 在隔离进程渲染 PNG 页面；界面显示页面并翻页，避免沙箱 iframe 中 PDF 插件空白。隔离子进程禁网、独立临时用户配置，禁用宏与 OLE/DDE 活动内容，无法读取源目录中的链接目标。使用已安装办公扩展的中文字体私有副本，避免缺字。探测系统安装或 `EVOWORK_OFFICE_CONVERTER`，不自动下载或调用 Office 云服务。不存在可用转换器/办公扩展/隔离环境或转换失败时明确显示原有正文预览及版式限制，不称为原版预览。页面渲染上限 20 页、PNG 合计 16 MB、单页 1600×2000 像素；截断时显示数量，不执行 PDF 中的脚本或链接。

记录范围限任务 cwd 内的非隐藏普通文件，跳过依赖/缓存与软链；每次扫描最多 5000 项、256 MiB，每文件撤销副本至多 32 MiB，总内容缓存至多 256 MiB。超限与读取失败可见，不能把未覆盖内容称为完整差异；旧任务不补造起点。回合之间发现外部编辑的文件禁止按任务起点撤销，本回合仍可按新起点恢复。撤销一个文件不更新其他文件的后态。当前不自动清理旧任务撤销副本，容量满后停存并明确提示。

不修改上游内核，不使用内核内部存储；本机循环地址桥仅服务本次桌面宿主，凭据不进入 renderer。
