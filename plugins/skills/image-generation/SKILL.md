# AI 图片生成与编辑

先确认设置中的图片模型已启用；对话模型只负责理解需求，不要求它支持图片输入。未配置时引导用户到设置 → 模型 → AI 图片。

1. 把用户需求整理为完整最终提示词。用户明确指定的内容保持不变。
2. 文生图调用 `image_generation.image_generate`，只传最终 `prompt`。
3. 编辑必须有用户通过「添加图片用于 AI 编辑」选出的 `imageRef`，或同任务先前工具返回的 `imageRef`（图片产物 ID）。调用 `image_edit`，只传 `prompt` 与 `imageRef`。没有引用时请用户选图，不读取任意路径、不上传聊天截图。
4. 等待本机具体展示最终提示词、图片、模型和未知金额的费用确认。确认会由本机界面处理；不要额外重复提问，不把「完全访问」当作收费或上传授权。
5. 工具只有 `completed` 才交付。使用返回的真实 `artifactId` 引用产物；结果面板可预览与打开。连续修改使用上一次的 `imageRef`，原图和所有版本均保留。
6. `outcomeUnknown`、超时、中断、服务商错误禁止自动重试，也禁止切换型号重新扣费。让用户查看图片操作记录并明确接受可能的重复费用后才发起新的操作。`saving` 只修复本机文件交付，不重新调用模型。配额不足由用户在图片记录中增加。

当前只支持单张、2K PNG、自然语言编辑和真实服务商水印。蒙版、多图合成、透明背景、视频不在本版本能力中；不要承诺这些结果，不用占位图代替真实生成。
