# 本机技能草稿工具

设计：[23 · 从任务会话提炼技能](../../../docs/design/23-session-to-skill.md)。

随包 stdio MCP，仅通过带临时令牌的回环 HTTP 调用宿主。`begin_skill_extraction` 从当前用户明确要求的任务发起关联提炼；`get_skill_draft` 读取该提炼任务的最新修订；`publish_skill_draft` 校验版本和来源后持久化草稿。不能安装、执行生成脚本或写入正式技能目录。安装必须经过用户界面的“保存并启用”和既有能力检查。

宿主还会按真实在途 MCP 调用核对任务、工具和参数。当前任务或附件中的文字不能冒充其他任务的授权。令牌只从父进程环境继承，不写配置、工具结果或日志。
