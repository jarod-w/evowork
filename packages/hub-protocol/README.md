# packages/hub-protocol —— 插件 Hub 的索引协议（无网络、无存储）

设计：[13 §4](../../docs/design/13-plugin-hub.md)（H1）。

| 消费者                    | 用它做什么                     |
| ------------------------- | ------------------------------ |
| `services/hub-client`     | 验签、解析索引、解内容包、校验 |
| `services/catalog`        | 更新判定、吊销范围             |
| `apps/desktop` 主进程     | 钉死的公钥类型、条目类型       |
| `evowork-hub` 的 CI（H2） | 签名发布、打确定性的内容包     |

## 这一包守住的几件事（结构上，不靠调用方自觉）

- **外层信封与策略包共用**（`@evowork/account` 的 `envelope.ts`，HF11）。签的是 `payloadJson` 原文。
- 解析是白名单式的：一个字段不对，整份索引不认。
- **没写许可（`NOASSERTION`）的条目只能指向上游固定提交**，不能指向我们的 CDN（HUB-Q5a=A）。
- 内容包路径只能是相对路径、不能有 `..`；上游地址只认 https。
- tar 读取器只认普通文件与目录：符号链接、硬链接、设备、`..`、绝对路径**整包拒绝**，不是跳过。
- 吊销范围写错（认不出的版本 / 范围）一律按「命中」处理：宁可多停用，不能放过。
