# EvoWork

**一句话交代工作，拿回能直接用的文件。**

EvoWork 是装在你电脑上的 AI 工作助手。你用一句话说清要什么 ——「根据这几张表写一份周报」「把这份合同的风险点整理成表格」「做一份 10 页的季度汇报」—— 它会自己规划、动手、核对，最后交给你 Word、Excel、PPT 这样的成品文件，而不是一段还要你复制、排版、再核对一遍的文字。

它在动你的文件之前先问你，你的文件在你自己的电脑上处理。

**[下载 macOS 版（Apple 芯片）](https://update.nucleant.cn/latest/EvoWork-0.0.6-mac-arm64-unsigned.dmg)** · 当前版本 0.0.6 · [更新记录](CHANGELOG.md) · 开源（MIT）

## 它能帮你做什么

- **交付成品文件**：Word 文档、Excel 表格、PPT、图表。默认 A4 纸张，自带中文字体，图表里的中文不会变成方框。
- **读懂你的资料**：PDF、Word、Excel、PPT 和压缩包都在本机解析；扫描件用本机 OCR 识别；放进资料库的文件可以按正文搜索。
- **联网查资料并标出处**：不需要另外申请搜索服务，回答里引用的网页会列出来源。
- **长任务不怕中断**：做的过程中显示进度，中断了可以接着做。用 `/goal` 给它一个持续目标和预算，预算用完就停下来，不会一直花下去。
- **定时自动做**：比如每周一早上 9 点生成周报。连续失败 3 次会自动暂停，不会在后台反复空跑。
- **生成和修改图片**：接入你自己的图片服务后，可以生成图片、用一句话修改、连续出几个版本。每次上传图片、每次产生费用之前都会先问你，原图不会被覆盖。
- **安装新技能**：从插件中心、单个文件或文件夹安装。安装前会列出这个技能会做什么，比如要运行哪些脚本、要访问哪些网址。
- **操作电脑上的其他应用**（实验功能，仅 macOS）：替你在别的应用里点按和输入，有风险的操作先问你。

## 放心交给它

> **文件处理、命令执行、定时任务都在这台电脑上完成。** 文档解析不会把你的原始文件传到云上。
>
> **模型调用需要联网。** 你的提问和相关上下文会发给你选择的模型服务商；EvoWork 的网关不保存这些内容。

这两句话也写在首次启动的第一屏，措辞是一样的。

**你决定它能自己做到哪一步。** 每次发送前选一个档位：

| 档位             | 它会怎么做                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| 请求批准（默认） | 编辑工作空间外的文件或使用互联网时询问你                                 |
| 完全访问         | 可以读写这台电脑上的文件并联网。开启前要你确认，并且只对当前任务生效     |
| 帮我批准         | 只对检测到的风险操作请求批准。**这一档还没接通**，界面上会置灰并写明原因 |

**删除和覆盖先问你。** 删除文件、覆盖已有的文件之前会弹出确认，写清是哪个文件。即使在「完全访问」下，删除文件的命令也会先问一次。你拒绝了，它不应该换个办法达成同样的结果 —— 我们专门为此测过、修过。

**碰不到的地方。** 系统目录、密钥与凭据、EvoWork 自身的配置会被拦截，完全访问也不能绕过。

**你的模型密钥只在本机。** 用系统钥匙串加密保存，界面上只显示最后四位，不会上传给我们。

**做不到就直说。** 缺组件、模型看不了图片、某个功能还没接通，界面会告诉你原因，而不是悄悄换成一个差一点的做法。

## 开始使用

1. 下载安装包，打开后把 EvoWork 拖进「应用程序」。
2. **第一次打开之前**，打开「终端」，粘贴下面这一行并回车：

    ```bash
    xattr -cr /Applications/EvoWork.app
    ```

    现在的安装包还没有 Apple 签名，不做这一步的话 macOS 会提示「已损坏，无法打开」—— 文件其实没有坏。拿到签名证书之后就不需要这一步了。

3. 打开后直接进入主界面，办公组件会从安装包中自动准备，不需要联网安装。任务文件默认保存在独立目录中，可在「设置 → 常规」更改保存位置。
4. 在「设置 → 模型」里添加你的模型密钥：DeepSeek、Kimi（Moonshot）、GLM（智谱），或其他兼容 OpenAI 接口的服务。**不需要注册 EvoWork 账号。**
5. 回到首页，说出你要什么，发送。

**升级**：在「设置 → 关于与更新」里检查更新。新安装包会下载到「下载」文件夹，手动安装即可。不会强制升级，旧版本照样能用。

## 现在还做不到的

- 只有 Apple 芯片（M 系列）Mac 的安装包。Intel Mac、Windows、Linux 还没有。
- 安装包没有签名，所以需要上面第 2 步。
- 「帮我批准」档还没接通。
- 删除和覆盖前的确认覆盖了常见的做法，还不是所有写法。
- 操作其他应用还是实验功能，只在 macOS 上验证过。
- 成品质量和你选的模型有关。轻量模型做复杂 PPT、表格的效果还没有系统评估过。

遇到问题、或者发现它做了不该做的事，欢迎[提 issue](https://github.com/jarod-w/evowork/issues)。

## 参与开发

桌面应用是 Electron + React + TypeScript；本机服务层是 Node；模型网关负责把各家模型的接口统一起来。

前置：Node ≥ 22.12，pnpm 10.30.3（`corepack enable`），Python ≥ 3.10。构建执行内核还需要 Rust，见 [编译与部署 §1–§2](docs/build-and-deploy.md)。

```bash
pnpm install
pnpm run check   # 格式 · lint · 类型 · 测试 · 内核补丁预算 · 协议形状 · 许可清单 —— 唯一的验收口径
pnpm run build
```

开发模式怎么跑、怎么打包，见 [编译与部署 §4–§5](docs/build-and-deploy.md)。
